## 时序图1 登录功能

```mermaid
sequenceDiagram
    participant 用户
    participant 前端
    participant NestJS
    participant MySQL

    用户->>前端: 输入邮箱/密码，点击登录
    前端->>前端: 前端格式校验
    前端->>NestJS: POST /auth/login
    NestJS->>MySQL: SELECT * FROM users WHERE email=?
    MySQL-->>NestJS: 返回用户记录
    NestJS->>NestJS: bcrypt.compare(password, hash)
    alt 密码正确 & 账号正常
        NestJS->>NestJS: 生成 accessToken + refreshToken
        NestJS-->>前端: 200 {accessToken, refreshToken}
        前端->>前端: Zustand 持久化 Token
        前端-->>用户: 跳转首页
    else 密码错误或账号封禁
        NestJS-->>前端: 401/403 错误信息
        前端-->>用户: 显示错误提示
    end
```

## 时序图2 发布案件功能

```mermaid
sequenceDiagram
    participant 用户
    participant 前端
    participant NestJS
    participant MySQL

    用户->>前端: 填写标题/内容/选择智能体/上传封面
    前端->>前端: 前端字符数校验 & 智能体数量校验
    前端->>NestJS: POST /rooms（携带 accessToken）
    NestJS->>NestJS: JWT Guard 验证 Token
    NestJS->>NestJS: ValidationPipe 校验 DTO
    alt 校验通过
        NestJS->>MySQL: INSERT INTO rooms（status=WAITING）
        MySQL-->>NestJS: 返回新建 room 记录
        NestJS-->>前端: 201 {roomId, ...}
        前端-->>用户: 弹出成功提示，引导进入辩论室
    else 校验失败
        NestJS-->>前端: 400 错误信息
        前端-->>用户: 显示错误提示
    end
```

## 时序图4 投票功能

```mermaid
sequenceDiagram
    participant 用户
    participant 前端
    participant NestJS
    participant MySQL
    participant 其他用户

    NestJS->>前端: WS voteStart
    前端->>前端: 渲染投票条，开始30秒倒计时
    用户->>前端: 点击智能体头像投票
    前端->>NestJS: POST /rooms/:id/vote {agentId}
    NestJS->>MySQL: SELECT * FROM votes WHERE userId=? AND roomId=?
    alt 未投票过
        NestJS->>MySQL: INSERT INTO votes
        NestJS->>MySQL: UPDATE agents SET wins（Prisma 原子操作 increment）
        MySQL-->>NestJS: 更新成功
        NestJS->>前端: WS voteUpdate（最新各方票数）
```
