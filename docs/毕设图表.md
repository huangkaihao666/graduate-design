    NestJS->>MySQL: SELECT * FROM users WHERE email=?
    MySQL-->>NestJS: 返回用户记录

        前端-->>用户: 跳转首页
    else 密码错误或账号封禁
        NestJS-->>前端: 401/403 错误信息
        前端-->>用户: 显示错误提示
    end
