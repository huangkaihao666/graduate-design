## 图2 登录注册流程图

```mermaid
flowchart TD
    A([开始]) --> B{已有账号?}
    B -- 否 --> C[填写邮箱/用户名/密码]
    C --> D[前端格式校验]
    D --> E{校验通过?}
    E -- 否 --> C
    E -- 是 --> F[POST /auth/register]
    F --> G{邮箱已存在?}
    G -- 是 --> H[返回错误提示] --> C
    G -- 否 --> I[bcrypt 加盐哈希密码]
    I --> J[写入 users 表]
    J --> K[颁发 accessToken + refreshToken]
    K --> L[前端 Zustand 持久化 Token]
    L --> M([进入首页])

    B -- 是 --> N[输入邮箱/密码]
    N --> O[POST /auth/login]
    O --> P{bcrypt 密码比对}
    P -- 失败 --> Q[返回邮箱或密码错误] --> N
    P -- 成功 --> R{账号是否封禁?}
    R -- 是 --> S[返回 403 封禁提示]
    R -- 否 --> K
```

## 时序图1 登录功能

```mermaid
sequenceDiagram
    participant 用户
    participant 前端
    participant NestJS
    participant MySQL

    用户->>前端: 输入邮箱/密码，点击登录
    前端->>前端: 前端格式校验
    前端->>NestJS: POST /auth/login
    NestJS->>MySQL: SELECT * FROM users WHERE email=?
    MySQL-->>NestJS: 返回用户记录
    NestJS->>NestJS: bcrypt.compare(password, hash)
    alt 密码正确 & 账号正常
        NestJS->>NestJS: 生成 accessToken + refreshToken
        NestJS-->>前端: 200 {accessToken, refreshToken}
        前端->>前端: Zustand 持久化 Token
        前端-->>用户: 跳转首页
    else 密码错误或账号封禁
        NestJS-->>前端: 401/403 错误信息
        前端-->>用户: 显示错误提示
    end
```

```mermaid
    NestJS->>NestJS: JWT Guard 验证 Token
    NestJS->>NestJS: ValidationPipe 校验 DTO
    alt 校验通过
        NestJS->>MySQL: INSERT INTO rooms（status=WAITING）
        MySQL-->>NestJS: 返回新建 room 记录
        NestJS-->>前端: 201 {roomId, ...}
        前端-->>用户: 弹出成功提示，引导进入辩论室
    else 校验失败
        NestJS-->>前端: 400 错误信息
        前端-->>用户: 显示错误提示
    end
```
