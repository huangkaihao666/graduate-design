# 功能验证手册

> 按照每个模块的步骤操作，看到对应现象说明功能正常。

## 一、人机协同辩论流程

**场景：考研值不值得全力以赴**

> 案件标题：「考研值不值得全力以赴」，智能体 A 为「毒舌现实主义者」，智能体 B 为「温柔共情者」，Bot C 为裁判。

### 1.1 基础流程

1. 登录后进入辩论广场，发起案件，选好 3 个智能体，进入辩论室
2. 点击「开始辩论」，Round1 智能体开始发言，**此时弹幕已开始收集**（不需要等 Round1 结束）
3. 在智能体发言期间就可以发弹幕，Round1 结束后聊天区顶部出现蓝色提示条：`支持「毒舌现实主义者」还是「温柔共情者」？说出你的理由（60 秒）`，并有倒计时，继续收集 60 秒
4. 在 Round1 发言期间 + 60 秒窗口内发送以下弹幕（混合有效和无效，验证过滤）：

   **应被注入（有效观点）：**
   - `我支持毒舌现实主义者，考研不是唯一出路，就业市场更看重实际能力`
   - `温柔共情者说的对，读研能让人想清楚自己真正想做什么`
   - `全力以赴考研会错过很多社会经验，代价太大了`
   - `站温柔共情者，知识本身就有价值，不能只看就业回报`

   **应被过滤（无效灌水）：**
   - `哈哈哈哈` （纯感叹，字数不足）
   - `666` （重复字符）
   - `前排` （与辩题无关）
   - `主播加油` （与辩题无关）
   - `啊啊啊啊啊啊` （重复字符超 60%）

5. 倒计时结束，提示条变为：`已收集 X 条有效观点注入第二轮辩论`
   - 有效数 X 应为 4（灌水的 5 条被过滤）

### 1.2 验证 RAG 注入效果

6. 观察 Round2（交叉反驳阶段）智能体的发言：
   - 毒舌现实主义者发言中应出现类似「有观众提到就业市场更看重实际能力……」
   - 温柔共情者发言中应出现类似「有用户认为知识本身有价值……」
   - 两方都会引用对己方有利的观点，不会照抄原文
7. 观察 Round3（裁判阶段）：
   - 裁判 Bot C 的发言应提及民意分布（如「支持毒舌现实主义者的观众更多」或「观众观点各半」）

### 1.3 验证立场识别

发送以下弹幕，验证 RAG 能否正确识别立场：

**全名命中（精确）：**

| 弹幕内容                               | 预期立场  | 判断依据                        |
| -------------------------------------- | --------- | ------------------------------- |
| `我支持毒舌现实主义者，他说的更有道理` | SUPPORT_A | 全名+支持词，关键词规则命中     |
| `温柔共情者说的对`                     | SUPPORT_B | 全名+「说的对」，关键词规则命中 |

**片段命中（模糊）：**

| 弹幕内容                   | 预期立场  | 判断依据                                           |
| -------------------------- | --------- | -------------------------------------------------- |
| `我支持毒舌，他说的更实际` | SUPPORT_A | 「毒舌」是「毒舌现实主义者」的片段，关键词规则命中 |
| `现实主义者说得对`         | SUPPORT_A | 「现实主义者」是片段，关键词规则命中               |
| `站温柔那边`               | SUPPORT_B | 「温柔」是「温柔共情者」的片段，关键词规则命中     |
| `共情者的观点更打动我`     | SUPPORT_B | 「共情者」是片段，关键词规则命中                   |

**纯语义（不含名字，向量判断）：**

| 弹幕内容                         | 预期立场                    | 判断依据                         |
| -------------------------------- | --------------------------- | -------------------------------- |
| `全力以赴考研值得，梦想不能妥协` | SUPPORT_B（温柔共情者）     | 语义向量更接近温柔共情者锚点     |
| `考研性价比太低了，不如直接工作` | SUPPORT_A（毒舌现实主义者） | 语义向量更接近毒舌现实主义者锚点 |
| `这个问题很复杂，两边都有道理`   | NEUTRAL                     | 两方相似度差值 < 0.05            |

**说明生效的现象**：

- 提示条显示的有效数量等于你发的有意义弹幕数（灌水被排除）
- Round2 智能体发言能自然引用你的弹幕内容（不照抄，会改写）
- Round3 裁判提及观众民意分布

## 二、话题标签

**怎么验证**

1. 进入辩论广场，顶部搜索栏下方应该有一排标签（职场 / 感情 / 学业 / 消费 / 家庭 / 法律），点击任意一个，案件列表会筛选出对应标签的案件
2. 发起辩论时，表单里有标签选择区域，最多选 3 个，提交后案件卡片上显示对应标签
3. 案件卡片上应该有情绪类型小标签（如"😰 焦虑"），这是发布时系统自动分析的结果

**说明生效的现象**：点击标签后列表只显示该标签下的案件；新发布的案件卡片上能看到标签和情绪类型。

## 三、案件点赞与收藏

**怎么验证**

1. 在辩论广场或案件详情页，找到点赞和收藏按钮，点击后按钮状态变化（高亮/填充），数字加 1
2. 再点一次取消，数字减 1
3. 进入"我的辩题"页，切换到"我的收藏" Tab，刚才收藏的案件应该出现在这里

**说明生效的现象**：按钮状态实时变化，收藏列表能看到对应案件。

## 四、AI 共情师

### 4.1 基础对话与 RAG 记忆

**场景：考研压力**

1. 点击左侧菜单「AI 共情师」，右侧显示欢迎卡片（首次进入无对话记录）
2. 点击「开始新对话」，进入聊天界面，辅导师自动发送开场白
3. 发送第一条消息：`考研还有三个月，我每天睡不着，感觉自己根本不可能上岸`
   - 辅导师应以流式打字机效果回复，语气温暖，先共情再追问感受，不直接给建议
4. 继续对话 2-3 轮，比如聊具体科目压力、作息、家人期望等
5. 关闭当前会话（侧边栏点击其他会话，或等待归档）
6. 点击「新对话」新建第二个会话，发送：`我最近又开始焦虑了，考研的事`
   - 辅导师的回复里应出现类似「上次你提到睡眠不好……」或主动关联之前聊过的内容

**说明生效的现象**：第二次对话时辅导师能自然引用第一次会话的内容，说明动态 RAG 记忆生效。

---

### 4.2 从辩论室进入（携带案件上下文）

**场景：考研相关辩论 → 共情师**

**入口一：辩论室左侧面板**

1. 进入一个主题为「考研值不值得全力以赴」的辩论室（或任意案件）
2. 在左侧面板底部找到「和 AI 共情师聊聊这个案件」按钮，点击
3. 页面跳转到 AI 共情师页面，欢迎卡片上方出现蓝色提示条：`已关联案件：考研值不值得全力以赴`
4. 点击「开始新对话」，对话创建后聊天顶部显示「关联案件：xxx」标签
5. 无需介绍背景，直接发送：`看了刚才的辩论，我更迷茫了`
   - 辅导师的开场白应主动提及案件名称，说明已了解背景

**入口二：结案报告页**

1. 辩论结束后进入结案报告页，右侧侧边栏底部有「有话想说？」卡片
2. 点击「和 AI 共情师聊聊」按钮，同样携带案件 ID 和标题跳转
3. 验证方式同入口一步骤 4-5

**说明生效的现象**：

- 跳转后欢迎页显示案件关联提示
- 新建会话后聊天顶栏出现「关联案件」标签
- 辅导师开场白主动提及案件内容，无需用户重复介绍背景

## 五、情绪预警

**怎么验证**

1. 用普通用户账号进入 AI 共情师，新建一个会话
2. 发送一条包含风险词的消息，比如：
   - "感觉撑不下去了"
   - "活着真的没意思"
   - "我不想继续了"
3. 等辅导师回复完毕（看到打字机停止）
4. 切换到管理员账号登录，进入管理端的"情绪预警"页面
5. 应该能看到刚才那条消息触发的预警记录，显示用户昵称、风险等级（HIGH）、一句话摘要说明
6. 点击"标记已跟进"，填写备注（如"已联系辅导员"），记录状态变为已处理

**说明生效的现象**：管理端情绪预警页出现该用户的 HIGH 级别记录，摘要能看出是什么情绪和原因。

> **补充验证**：对同一个会话再发一条风险消息，管理端不会出现重复的预警记录（防重复机制）。

## 六、创建智能体

**怎么验证**

1. 点击"创建智能体"菜单，填写名称、人设描述、System Prompt，选择可见性为"申请公开"，提交
2. 进入"我的智能体"列表，能看到刚创建的智能体，状态显示"审核中"
3. 切换管理员账号，进入管理端"智能体审核"，找到刚提交的智能体，点击通过
4. 回到普通用户，进入"智能体图鉴"，能看到该智能体卡片上有"用户创建"角标
5. 发起辩论时，智能体选择列表里出现"我的智能体"分组，可以选择自建的智能体参与辩论

**说明生效的现象**：审核通过后智能体出现在 AI 图鉴，发起辩论时可以选用。

## 七、关注动态

**怎么验证**

1. 进入某个用户的个人主页，点击"关注"按钮，按钮变为"已关注"
2. 点击左侧"关注动态"菜单，动态流里出现该用户发布的辩论案件
3. 被关注的用户发起新辩论后，在消息通知页会收到一条"XXX 发起了新辩论"的通知

**说明生效的现象**：关注后动态流有内容，对方发新案件后通知页有提醒。

---

## 八、成就中心

**怎么验证**

1. 点击"成就中心"菜单，顶部显示当前等级和经验值进度条
2. 完成一个解锁条件，比如发布第一个案件（对应成就"初出茅庐"）
3. 回到成就中心，"初出茅庐"徽章从灰色变为高亮
4. 消息通知页应该收到一条成就解锁提醒
5. 查看排行榜，能看到 Top 20 用户的等级和经验值排名

**说明生效的现象**：徽章高亮，通知页有解锁提醒，经验值增加。

---

## 九、消息通知

**怎么验证**

1. 触发任意一种通知（被关注、案件辩论开始、成就解锁、管理员发公告）
2. 顶部导航栏的通知图标出现红色角标和数字
3. 点击进入通知中心页，看到对应通知条目，点击可跳转到相关页面
4. 点击"全部已读"，角标消失

**说明生效的现象**：角标数字实时变化，通知列表按类型显示不同图标和内容。

## 十、管理端数据统计

**怎么验证**

1. 管理员登录进入数据统计页
2. 顶部概览卡片显示用户总数、案件总数、消息总数
3. 页面中有话题标签热度饼图（各标签下案件数量分布）
4. 有平台情绪分布图（近期案件焦虑/愤怒/迷茫占比）
5. 有心理辅导使用频次趋势图

**说明生效的现象**：三个新增图表有数据展示（需要平台有一定使用数据）。

## 十一、管理端话题管理

**怎么验证**

1. 管理员进入"话题管理"，能看到现有标签列表及各标签下的案件数量
2. 新增一个标签，回到辩论广场，筛选栏出现新标签
3. 编辑标签名称或权重，辩论广场标签顺序随权重更新

**说明生效的现象**：新增标签实时出现在辩论广场筛选栏。

## 十二、管理端公告管理

**怎么验证**

1. 管理员进入"公告管理"，创建一条公告，填写标题和内容
2. 发布后，切换到普通用户账号，消息通知页应该收到一条系统公告通知
3. 平台首页 Banner 区域展示最新公告内容

**说明生效的现象**：普通用户通知页出现公告，首页 Banner 有内容。
