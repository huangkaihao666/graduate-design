# 基于多智能体协同与个性化RAG的大学生智能决策与情绪支持平台

> **项目定位**：面向大学生群体，提供多智能体辩论决策、情绪疏导、社区互动三位一体的智能支持平台。
>
> 🔴 **红色标注** = 新增功能模块

---

### 2.3 发起辩论（现有）

### 2.4 辩论室（现有）

- WebSocket 实时连接，打字机流式输出
- 三轮辩论：Round1 立场陈述 → Round2 交叉反驳 → Round3 BotC 裁决
- 右侧弹幕聊天区，实时在线人数
- 30 秒投票窗口，实时票数更新

<span style="color:red">**🔴 新增：人机协同辩论流程**</span>

<span style="color:red">参考真实辩论赛流程重新设计，用户观点在最合理的时机介入：</span>

```
Round1：BotA、BotB 并发陈述各自立场
    ↓
【用户观点征集 60秒】
  用户刚看完两方立场，此时最有发言欲
  提交"你支持哪方？为什么"，可为他人观点点赞
    ↓
Round2：针对性交叉反驳
  BotA 收到：BotB立场 + 支持BotB的用户观点Top3 → 逐一反驳
  BotB 收到：BotA立场 + 支持BotA的用户观点Top3 → 逐一反驳
  （用户观点成为"对方弹药"，Bot需正面回应，更有戏剧张力）
    ↓
Round3：BotC 综合裁决
  收到完整辩论记录 + 用户观点分布统计
  裁决中可引用"有X位观众认为..."
  输出多维行动建议
    ↓
30秒投票窗口
```

<span style="color:red">**用户观点介入的合理性**：Round1 后征集，用户有具体内容可评论；注入方式为"给对方看支持己方的观点并反驳"，而非简单参考，观点真正参与辩论而不是走过场。</span>

### 2.9 🔴 心理辅导（新增菜单）

<span style="color:red">**全新模块**：共情辅导师，体验类似 ChatGPT 的持续对话，基于 Coze 共情人格 Bot + 心理学 RAG 知识库（CBT认知行为疗法、非暴力沟通、焦虑干预手册）</span>

<span style="color:red">**三种入口，三种场景**：</span>
<span style="color:red">- **随时倾诉**：主动打开菜单，新建会话或继续上次对话，辅导师基于历史情绪记录主动关心（"上次你聊到XXX，最近怎么样了？"）</span>
<span style="color:red">- **辩论后延伸**：从结案报告底部入口进入，辅导师已读取案件内容+辩论结论+用户立场，无需重复描述背景，直接针对性疏导</span>
<span style="color:red">- **测评后引导**：情感测评检测到高压情绪（强度>70）时，提示跳转辅导，携带测评结果作为上下文</span>

<span style="color:red">**会话机制**：</span>
<span style="color:red">- **多会话管理**：左侧会话列表（类似 ChatGPT 侧边栏），可新建会话、切换历史会话、删除会话</span>
<span style="color:red">- **持续对话**：同一会话内完整保留消息历史，辅导师始终记得本次聊天内容，支持无限轮次对话</span>
<span style="color:red">- **跨会话记忆**：新建会话时，辅导师 System Prompt 中注入过往会话的情绪小结，实现跨会话的长期记忆</span>
<span style="color:red">- **自动归档**：超过 30 分钟无消息自动结束会话，生成情绪小结（一句话概括本次情绪变化）</span>

<span style="color:red">**功能点**：</span>
<span style="color:red">- SSE 流式输出，打字机效果，体验流畅</span>
<span style="color:red">- 消息支持 Markdown 渲染（辅导师可以用列表、加粗等格式化输出）</span>
<span style="color:red">- 会话标题自动生成（取第一条用户消息的前20字）</span>
<span style="color:red">- 每次会话结束后生成情绪小结（情绪类型 + 关键词 + 一句话建议）</span>
<span style="color:red">- 个人中心可查看情绪历史趋势（基于所有会话的情绪小结汇总）</span>

## 五、技术架构亮点

### 三层 RAG 架构

```
第一层：系统固定知识库（现有）
  Bot A → 博弈论/影响力
  Bot B → 非暴力沟通
  Bot C → 民法典/劳动合同法

第二层：用户个性化知识库（新增）
  用户上传文档 → Coze API 写入私有知识库
  发起辩论时动态绑定用户知识库到对应 Bot

第三层：共情辅导师知识库（新增）
  挂载心理学专业资料（CBT/焦虑干预/非暴力沟通）
  + 检索用户历史情绪记录作为上下文
```

### 人机协同辩论流程（新增）

```
Round1（AI立场陈述）
    ↓
用户观点征集窗口（60秒）
    ↓
Round2（AI结合用户观点交叉反驳）
    ↓
Round3（BotC综合用户观点+AI立场裁决）
    ↓
投票
```
