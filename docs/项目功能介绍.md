> **项目定位**：面向大学生群体，提供多智能体辩论决策辅助、情绪辅导、社区互动三位一体的智能平台。
>
> 🔴 **红色标注** = 新增功能模块

### 2.4 辩论室（现有）

- WebSocket 实时连接，打字机流式输出
- 三轮辩论：Round1 立场陈述 → Round2 交叉反驳 → Round3 BotC 裁决
- 右侧弹幕聊天区，实时在线人数
- 30 秒投票窗口，实时票数更新

<span style="color:red">**🔴 新增：人机协同辩论流程**</span>

<span style="color:red">参考真实辩论赛流程重新设计，用户观点在最合理的时机介入：</span>

```
Round1：BotA、BotB 并发陈述各自立场
    ↓
【用户观点征集 60秒】
  聊天区顶部提示条显示双方智能体名字，引导用户明确表态
  例如："支持「毒舌现实主义者」还是「温柔共情者」？说出你的理由"
  用户正常发弹幕即参与，零额外操作
    ↓
RAG 过滤处理（用户无感知）
  ① 过滤灌水：过滤哈哈/666/刷屏等无效内容
  ② 语义去重：合并语义高度相似的重复观点
  ③ 立场识别（参考用）：记录每条观点的立场倾向，供统计展示
  保留所有有效观点（最多20条），犀利、情绪化、极端观点只要相关全部保留
    ↓
Round2：针对性交叉反驳
  BotA 和 BotB 均收到：对方 Round1 发言 + 全量有效用户观点
  prompt 说明：观点来自真实用户，请自行判断哪些支持你的立场，自然引用 1-2 条
    ↓
Round3：BotC 综合裁决
  收到完整辩论记录 + 全量有效观点列表
  自行分析民意分布，在裁决中引用并说明
    ↓
30秒投票窗口
```

<span style="color:red">**交互说明**：不弹窗打断，直接复用弹幕输入框。Round1 结束后聊天区顶部出现轻提示条，显示双方智能体名字，用户正常发弹幕即参与征集，零额外操作。征集结束后提示条变为"已收集 XX 条有效观点注入第二轮辩论"。</span>

<span style="color:red">**本地 RAG 过滤（用户无感知）**：弹幕在后台经过本地 ChromaDB + Ollama 处理。RAG 的核心职责是**过滤灌水**，立场识别结果仅供参考和统计，不强依赖——让智能体自己读懂观众的声音，比系统预先贴标签更准确、更自然。这是平台**云端+本地混合 RAG 架构**的第三层。</span>

### 2.9 🔴 AI 共情师（新增菜单，原"心理辅导"）

<span style="color:red">**全新模块**：共情辅导师，体验类似 ChatGPT 的持续对话，基于 Coze 共情人格 Bot + 心理学 RAG 知识库（CBT认知行为疗法、非暴力沟通、焦虑干预手册）+ 个性化情绪记忆图谱</span>

<span style="color:red">**三种入口，三种场景**：</span>
<span style="color:red">- **随时倾诉**：主动打开菜单，新建会话或继续上次对话，辅导师基于个性化情绪档案主动关心（"上次你聊到XXX，最近怎么样了？"）</span>
<span style="color:red">- **辩论后延伸**：从结案报告底部入口进入，辅导师已读取案件内容+辩论结论+用户立场，无需重复描述背景，直接针对性疏导</span>
<span style="color:red">- **测评后引导**：情感测评检测到高压情绪（强度>70）时，提示跳转辅导，携带测评结果作为上下文</span>

<span style="color:red">**自定义辅导师（个性化核心功能）**：</span>
<span style="color:red">新建会话时可选择辅导师身份：</span>
<span style="color:red">- **默认共情师**（推荐）：系统内置，挂载心理学知识库，经过共情风格调优，适合大多数情绪倾诉场景</span>
<span style="color:red">- **我的智能体**：从用户自建且审核通过（`status=APPROVED`）的智能体中选择，风格完全由用户自己的 Prompt 决定；选择后显示提示"自建智能体的风格由你定义，体验可能与默认共情师不同"</span>
<span style="color:red">选择的辅导师绑定在当次会话上，同一用户的不同会话可以使用不同辅导师，历史会话列表显示对应辅导师名称。</span>

<span style="color:red">**会话机制**：</span>
<span style="color:red">- **多会话管理**：左侧会话列表（类似 ChatGPT 侧边栏），可新建会话、切换历史会话、删除会话</span>
<span style="color:red">- **持续对话**：同一会话内完整保留消息历史，辅导师始终记得本次聊天内容，支持无限轮次对话</span>
<span style="color:red">- **动态 RAG 记忆**：每次会话结束后，Coze 生成一句话情绪摘要（格式：[情绪类型] 核心事件，如"[焦虑] 考研压力大，倾向被倾听"），向量化后存入本地 ChromaDB 用户专属集合；用户打字时前端防抖 300ms 触发预检索，结果缓存在后端内存 Map；发送消息时直接读取缓存注入 prompt，消除 Ollama 嵌入延迟。记忆注入位置在最后一条用户消息前（紧贴当前消息），附带结构化引用指引，让模型自然提及而不生硬列举</span>
<span style="color:red">- **自动归档**：定时任务每 5 分钟扫描，超过 5 分钟无消息的会话自动关闭，异步生成情绪摘要 + 向量化后归档；新建会话时也会触发上一个活跃会话的归档</span>

<span style="color:red">**个性化情绪记忆图谱**（新增核心功能）：</span>
<span style="color:red">通过长期对话数据动态构建用户情绪档案，包含三个维度：</span>
<span style="color:red">- **情绪模式**：近期主导情绪类型 + 趋势（改善中/稳定/持续低落），描述性记录，非疾病诊断</span>
<span style="color:red">- **核心困扰话题**：从历史会话中提取用户反复提及的话题（学业/人际/感情/规划等），按频率排序</span>
<span style="color:red">- **应对偏好**：用户倾向被倾听还是获得建议，倾向情感共鸣还是理性分析，辅导师据此调整风格</span>

<span style="color:red">**功能点**：</span>
<span style="color:red">- SSE 流式输出，打字机效果，体验流畅</span>
<span style="color:red">- 消息支持 Markdown 渲染（辅导师可以用列表、加粗等格式化输出）</span>
<span style="color:red">- 会话标题自动生成（取第一条用户消息的前20字）</span>
<span style="color:red">- 每次会话结束后异步生成情绪小结，同步更新情绪档案</span>
<span style="color:red">- 个人中心展示"我的情绪档案"卡片：近期情绪趋势、常聊话题、辅导偏好、累计辅导次数</span>

## 五、技术架构亮点

### 四层 RAG 架构

```
第一层：智能体专业知识库（静态云端 RAG，现有）
  Bot A → 博弈论/影响力
  Bot B → 非暴力沟通
  Bot C → 民法典/劳动合同法

第二层：用户私有知识库（静态云端 RAG，新增）
  用户上传文档 → Coze API 写入私有知识库
  发起辩论时动态绑定到对应 Bot

第三层：弹幕灌水过滤（本地静态 RAG，新增）
  ChromaDB + Ollama 过滤灌水内容（哈哈/666/刷屏等）
  立场识别（双轨）：关键词规则优先 + 动态语义锚点兜底
  立场结果仅供统计，全量有效观点注入 prompt 让智能体自行判断

第四层：用户情绪记忆图谱（本地动态 RAG，新增）
  每次辅导会话结束 → Coze 生成一句话摘要 → 向量化存入用户专属 ChromaDB 集合
  用户打字时预检索（防抖300ms），结果缓存内存消除延迟
  发消息时读缓存，将历史记忆注入最后一条用户消息前
  知识库随用户使用持续增长，越聊越懂用户
```
