### 技术栈说明

| 技术          | 用途                                                                             | 备注                           |
| ------------- | -------------------------------------------------------------------------------- | ------------------------------ |
| **NestJS**    | 后端主框架，提供 REST API 和 WebSocket 服务                                      | TypeScript，模块化架构         |
| **React 18**  | 前端 UI 框架                                                                     | 配合 Ant Design 组件库         |
| **MySQL**     | 主数据库，存储用户/案件/消息等结构化数据                                         | 通过 Prisma 操作               |
| **Prisma**    | ORM，管理数据库 schema 和迁移，提供类型安全的数据库查询                          | 替代手写 SQL                   |
| **Socket.IO** | 辩论室实时通信，推送弹幕/辩论进度/投票事件                                       | 基于 WebSocket                 |
| **Coze API**  | 调用扣子平台的 AI Bot，驱动辩论智能体对话和共情师对话                            | 付费云端服务，需要 API Key     |
| **ChromaDB**  | 本地向量数据库，存储弹幕嵌入向量（第三层RAG）和用户情绪记忆摘要向量（第四层RAG） | 开源免费，本地运行             |
| **Ollama**    | 本地运行 `nomic-embed-text` 嵌入模型，将文本转换为向量供 ChromaDB 检索           | 开源免费，本地运行，不需要 GPU |
| **FastAPI**   | Python 微服务框架，封装 ChromaDB + Ollama 的 RAG 逻辑，供 NestJS 通过 HTTP 调用  | 开源免费                       |

## 重构核心变化

### 1. 平台定位升级

- 原：辩论围观平台（功能单一）
- 新：决策辅助 + 情绪辅导双轮驱动，目标用户聚焦大学生

### 2. 新增菜单（用户端）

- `创建智能体`：用户自定义 Prompt + 上传私有知识库
- `AI 共情师`：持续对话辅导，动态 RAG 情绪记忆图谱
- `情绪雷达`：情感分析工具，历史情绪趋势
- `关注动态`：社区关系与动态流
- `成就中心`：等级经验 + 成就徽章 + 排行榜
- `消息通知`：独立通知中心页

### 3. 新增菜单（管理端）

- `智能体审核`：审核用户公开的自建智能体
- `话题管理`：管理话题标签
- `公告管理`：发布系统公告

### 4. 四层 RAG 架构（核心技术亮点）

| 层次   | 用途                     | 技术                           |
| ------ | ------------------------ | ------------------------------ |
| 第一层 | 智能体专业知识库         | Coze 云端 RAG（现有）          |
| 第二层 | 用户私有知识库           | Coze 云端 RAG（新增）          |
| 第三层 | 弹幕观点过滤+立场识别    | 本地 ChromaDB + Ollama（新增） |
| 第四层 | 用户情绪记忆图谱（动态） | 本地 ChromaDB + Ollama（新增） |

### 5. 辩论流程升级（人机协同）

```
Round1（AI立场陈述）→ 用户弹幕征集60秒（复用聊天框，RAG过滤灌水+识别立场）
→ Round2（交叉注入：支持对方的用户观点给己方Bot反驳）
→ Round3（BotC综合用户观点分布裁决）→ 投票
```

### 6. 数据库扩展

- 原：8张表
- 新：18张表（新增 UserEmotionProfile、KnowledgeBase、KnowledgeDocument、UserOpinion、CounselingSession、CounselingMessage、SentimentRecord、Tag、RoomTag、UserRelation、Achievement、Announcement 等）
- 详见 `docs/模块实现方案.md` 模块0

## 实现顺序

```
第一批（基础功能）：数据库迁移 → 话题标签 → 点赞收藏 → 辩论室用户观点 → 情感分析
第二批（核心新模块）：AI 共情师 → 创建智能体 → 关注动态
第三批（锦上添花）：成就中心 → 管理端扩展 → 通知独立页
```
